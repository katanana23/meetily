### 4. ЛОГИКА И FLOW

#### ✅ Исправлен flow записи

**Проблема:**
- `isRecording` менялся, но редирект не срабатывал
- Двойное срабатывание `handleStartRecording`
- Нет состояния загрузки

**Решение:**
```tsx
const [isStarting, setIsStarting] = useState(false);

const handleStartRecording = async () => {
  if (isStarting || isRecording) return; // защита от двойного клика
  
  setIsStarting(true);
  try {
    await recordingService.startRecordingWithDevices(...);
    
    // Даём время для установки isRecording в true
    setTimeout(() => {
      router.push('/?recording=true');
    }, 300);
    
    toast.success('Запись началась');
  } catch (error) {
    toast.error('Ошибка запуска записи');
    setIsStarting(false); // возвращаем кнопку
  }
};

// Автоматический редирект при изменении isRecording
useEffect(() => {
  if (isRecording && !isStarting) {
    router.push('/?recording=true');
  }
}, [isRecording, router, isStarting]);
```

✅ **Button loading state:**
```tsx
<Button
  view="action"
  size="xl"
  onClick={handleStartRecording}
  disabled={isStarting || isRecording}
  loading={isStarting}
>
  {isStarting ? 'Запуск...' : 'Начать запись'}
</Button>
```
