# Функциональный аудит Aid Meetings

## КРИТИЧЕСКИЕ НАХОДКИ

### 1. ❌ Кнопка "Новая запись" не работает
**Проблема**: В `Home.tsx` строка 29-31:
```tsx
const handleStartRecording = () => {
  router.push('/?recording=true');
};
```
Переход на `/?recording=true` НЕ запускает запись, только меняет URL.

**Ожидание**: Кнопка должна вызвать `recordingService.startRecording()` или открыть диалог выбора микрофона.

**Состояние в mock**: В mock-режиме запись тоже не запускается.

---

### 2. ❌ Кнопка "Импортировать" не открывает диалог
**Проблема**: В `Home.tsx` строка 33-35:
```tsx
const handleImportAudio = () => {
  console.log('Import audio');
};
```
Только логирует в консоль, не открывает `ImportAudioDialog`.

**Ожидание**: Должна открыть диалог импорта через `ImportDialogProvider`.

---

### 3. ⚠️ Список встреч: неполные данные
**Проблема**: В `SidebarProvider.tsx` строка 100-105:
```tsx
const transformedMeetings = meetings.map((meeting: any) => ({
  id: meeting.id,
  title: meeting.title
}));
```
Теряются `created_at`, `duration`, `status`.

**Результат**: В UI отображается только название, дата и длительность показываются как `undefined`.

---

### 4. ⚠️ Поиск работает, но UI не адаптирован
**Проблема**: Поиск вызывает `searchTranscripts()`, но результаты (`searchResults`) не используются в `Home.tsx`.

**Текущее поведение**: Фильтрует локальный массив `meetings`, который содержит только id + title.

---

### 5. ⚠️ Hover состояния слишком слабые
**Проблема**: В списке встреч hover едва заметен:
```tsx
className="hover:bg-muted/50"
```
50% прозрачности делает эффект почти невидимым.

---

### 6. ❌ Recording flow в mock mode не демонстрирует процесс
**Mock режим**: Есть сценарий `recording`, но он не интегрирован с кнопкой "Новая запись".

---

### 7. ⚠️ Empty state недостаточно информативен
**Текст**: "Пока нет ни одной записи" + "Нажмите «Начать запись»..."

**Проблема**: Кнопка называется "Новая запись", а текст ссылается на "Начать запись".
