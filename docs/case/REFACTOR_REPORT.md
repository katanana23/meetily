# Рефакторинг Aid Meetings: от Dashboard к Productivity Workspace

## Резюме

Выполнен полный визуальный и композиционный рефакторинг интерфейса Aid Meetings с переходом от декоративного bento-dashboard к функциональному desktop productivity workspace в стиле Yandex Gravity UI / Linear / Raycast.

---

- ❌ Glassmorphism, backdrop-filter, blur
- ❌ Градиенты (from-accent/10 to-accent/5)
- ❌ Декоративные круги вокруг иконок (72px, 56px)
- ❌ Oversized CTA блоки, занимающие 7 колонок

## Дизайн-система

### Типографика (Gravity UI inspired)

```css
Page title:    24px / 28px / 600
Section title: 16px / 20px / 600
Body:          14px / 20px / 400
Secondary:     13px / 18px / 400 (muted)
Label:         12px / 16px / 500
```

**Было**: 28/22/15/13 (слишком крупно для desktop)  
**Стало**: 24/16/14/13/12 (Gravity UI scale)

### Spacing

```
4, 8, 12, 16, 20, 24, 32
```

Основные отступы: 24-32px для page layout, 12-16px внутри компонентов.

### Colors

- Плоские цвета, без градиентов
- Тёплый нейтральный фон (43 20% 96%)
- Янтарный акцент (38 92% 50%)
- Контраст текста ≥4.5:1, границ ≥3:1
- Тёмная тема: не чисто чёрный фон (24 10% 10%)

### Radii

```
Карточки: 8px (rounded-lg)
Кнопки:   6px (rounded-md)
Чипы:     999px (rounded-full)
```

**Было**: 24px карточки, 16px кнопки  
**Стало**: 8px/6px (системные, Gravity UI)
