## Не реализовано

### 1. Моки для браузера ❌
- `frontend/src/dev/mock-tauri/` существует, но неполный
- Нужно ~40 команд и 6 событий по `docs/recon.md` раздел 4
- Без моков невозможна проверка в браузере с `?mock=full`

### 2. Скриншоты ❌
- Не созданы из-за отсутствия моков
- План: 3 экрана × 2 темы в `docs/case/shots/`

### 3. Подключение логики ❌
- Старт/стоп записи: кнопки есть, но вызовы заглушены `console.log`
- Импорт аудио: кнопка есть, диалог не открывается
- Поиск: кнопка есть, логика не подключена

### 4. Реальный уровень звука ❌
- Событие `audio-levels` существует, но не подключено к визуализации
- Сейчас случайные высоты полосок

### 5. Дополнительные фичи ❌
- Группировка встреч по датам (нет `created_at` в `api_get_meetings`)
- Редактирование транскрипта (нет команды)
- Задачи с исполнителем (нет хранения статусов)
- Плеер и переход к моменту (требует `read_audio_file`)

## Принятые решения

### 1. Упрощения
- Резюме рендерится `dangerouslySetInnerHTML`, а не BlockNote (BlockNote сложен для MVP)
- Сайдбар без свёрнутого режима (только 256px)
- Встречи без группировки по датам (нет данных от ядра)

### 2. Компромиссы
- Остановка и открытие встречи: +1 клик (было автооткрытие, стало клик по списку)
- Статичная сборка (`pnpm build`) падает на runtime (провайдеры обращаются к Tauri при SSG)
- Для проверки нужен `pnpm dev` или полный мок

### 3. Сохранено
- Контракты команд и событий не менялись
- Оригинальный интерфейс не тронут
- Tailwind 3.4 не обновлялся
