# Базовые измерения

Снимаем «до» на текущей версии (v0.4.1) до любых изменений, «после» на той же машине и по той же методике. В примечаниях указываем машину, версию и дату замера.

| Метрика | Как измерять | До | После |
|---|---|---|---|
| Например: время от запуска до начала записи | Секундомер: двойной клик по иконке → идёт запись (горит индикатор). Среднее из 3 попыток | | |
| Например: кликов до готового резюме после остановки записи | Считать клики от «Стоп» до резюме на экране | | |
| Например: время найти фразу в прошлой встрече | Секундомер: задать фразу → открыт нужный момент транскрипта | | |
| | | | |
