# Список встреч (главная)

Читать перед правкой главной: заголовок, фильтры, поиск, строки списка. Перенесено из CLAUDE.md. Пути от `frontend/src/shade/`.

- Одной плиткой, как в Я.Музыке (`Page`, раскладка tile), шапка общая (large title, см. [frame.md](frame.md#шапка-componentspagetsx)). Корневой экран: большой заголовок в одной строке с действиями.
- Большой заголовок «Встречи» 36/40 и серая подпись, ниже чипы-фильтры Все, С итогами, Корзина (раздела «Не распознано» нет). Выбранный чип `.shade-chip-on` ([foundations.md](foundations.md#цвет-с-ролью)).
- В полосе справа круглые кнопки 56 px: поиск с лупой и импорт аудио.
- Поиск: поле выезжает влево отдельной таблеткой до 280 px, кнопка остаётся на месте, и лупа в ней поворотом превращается в крестик «Закрыть поиск». Чипы остаются. Esc и крестик сворачивают и очищают, пустое поле сворачивается при потере фокуса. Обводка фокуса внутри поля.
- Ниже список, строки без вложенных карточек с миниатюрой состояния 48 px (`components/MeetingRow.tsx`). От 1100 px ширины списка две колонки (`@container`, `@[1100px]` в `pages/Home.tsx`).
- Новая встреча после «Остановить» первой строкой в «Сегодня» (`PendingRow`): [recording-outcome.md](recording-outcome.md#после-остановить).
- Фильтр «Корзина», «Восстановить», «Удалить насовсем»: [recording-outcome.md](recording-outcome.md#3-корзина-libmeeting-trashts-librecording-trashts).
- Кнопка записи в покое показывается только здесь: [recording.md](recording.md#док-записи-componentsrecorddocktsx).
- Длительность в строке: длина файла звука, см. [meeting.md](meeting.md#длительность).
