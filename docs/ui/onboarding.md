# Первый запуск

Читать перед правкой мастера первого запуска. Перенесено из CLAUDE.md. Пути от `frontend/src/shade/`.

## Каркас
- `components/onboarding/ShadeOnboarding.tsx`, показывает `app/layout.tsx` при `NEXT_PUBLIC_UI=shade`; оригинальный мастер для `original`. Логика из `useOnboarding()` оригинала.
- Минималистично: одна плитка до 600 px по центру на фоне окна, сверху точки шага, подложка кнопок окна на месте. Каждый шаг помещается в окно 1100 × 700.
- Внутри `--tile-pad`, как у всех плиток; отступы по шкале 8 / 12 / 16 / 20 / 24 / 32.
- Заголовок шага кирпичиком (`TITLE_CLASS` в `components/onboarding/ui.ts`: 22/28, balance, колонка около 30 символов); описания `HINT_CLASS` (pretty, до 52 символов). «Shade» и предлоги не отрываются: неразрывный пробел `NBSP` в строках.
- Обе обложки с высотой пропорционально ширине (8:3).

## Шаги
1. Обложка с живым показом работы (`HelloStep`, цикл `CYCLE_MS`): кнопка «Записать» становится капсулой с таймером, реплики по очереди через 150 мс, их сменяют итоги на мягком тоне Indigo (`.shade-role-indigo-soft`, 15 px 500, Lc ≈ 75), итоговый кадр стоит 1,7 с и гаснет. Реплики и капсула одной группой по оптическому центру, около 65 % обложки. Ниже логотип, одна строка «Нажмите «Записать», остальное сделает Shade» и «Начать». Загрузка моделей стартует уже здесь.
2. «Доступ к звуку» (`AccessStep`, только macOS): обложка с показом запроса macOS (стилизованное окно, указатель подходит сбоку по кривой и нажимает «Разрешить»; при доступе стоит «Доступ есть», при отказе стоит окно без указателя). Карточки «Микрофон» (обязателен) и «Звук с компьютера», «Продолжить» (неактивная нейтральная, лайм только у активной) и тихая «Позже».
3. «Почти готово» (`ReadyStep`): прогресс модели распознавания, пропускается, если она скачана.

## Доступ и отказы
- `useAccessChecks`: «Открыть настройки» с `preferencePane` (`SETTINGS_PANE` в `lib/onboarding.ts`), при возврате фокуса перепроверка, неизменившийся ответ нейтрально «Проверим при первой записи».
- У вызовов ядра предел `SLOW_MS` (`lib/onboarding.ts`), потом «Продолжить всё равно».

## Завершение и движение
- В конце без `window.location.reload()`: `completeOnboarding()`, затем `onComplete`, layout заново монтирует провайдеры через `key`, приложение проявляется (`.shade-app-enter`).
- Смена шагов размытием и сдвигом (`.shade-ob-*`). При `prefers-reduced-motion` без движения, показы стоят на итоговом кадре.
- Полоски в показе украшение, а не уровень звука.
